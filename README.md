I'm a **Civil Engineering student** and **BIM Automation Consultant** living at the weird, chaotic intersection of **Construction, Software Engineering, and Artificial Intelligence**. 

While normal civil engineers calculate beam loads by hand, I write **Python & C# scripts** so the computer does the crying for me. My life goal is simple: **eliminate repetitive clicking in Revit**, build intelligent **Digital Twins**, and make buildings talk back using **LLMs & RAG**.

* ⚙️ **Lazy-Genius Workflows:** Hooking up **n8n**, APIs, and webhooks so my software works while I sleep.
