## 👨‍💻 About me

I'm a Civil Engineering student and BIM Automation Consultant building tools at the intersection of construction, software, and artificial intelligence.

My focus is practical engineering automation: reducing repetitive work, creating smarter BIM workflows, and making building information more useful.

- 🏗️ Revit automation with Python, C#, PyRevit, and the Revit API
- 🤖 AI assistants, retrieval-augmented generation (RAG), and LLM-powered workflows
- 🌐 Digital twins and building intelligence
- ⚙️ Workflow automation with n8n and APIs
- 🔬 Exploring practical applications of AI in the AEC industry
